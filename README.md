# 合同会社Link ホームページ（ページ分け版）

元の1枚スクロール版 `index.html` を、ページごとに分けた版です。
デザイン・文章は元のまま変えていません。変えたのは「構造」だけです。

## ファイル構成

| ファイル | ページ | よく触る？ |
|---|---|---|
| `index.html` | トップ | たまに |
| `company.html` | 会社案内 | たまに |
| `business.html` | 事業内容 | たまに |
| `recruit.html` | 採用情報 | 募集を始めるとき |
| `news.html` | お知らせ | ★一番よく更新する |
| `contact.html` | お問い合わせ | 連絡先が決まったら |
| `privacy.html` | プライバシーポリシー | ほぼ触らない |
| `assets/style.css` | 全ページ共通のデザイン | 基本触らない |
| `assets/content.js` | 文章データを読み込む仕組み | 触らない |
| `content/*.json` | 各ページの文章データ。Pages CMSでは入力フォームとして表示される | ★フォームから編集 |
| `assets/logo.png` | ロゴ画像（全ページ共通） | 基本触らない |
| `.pages.yml` | スマホ編集ツール Pages CMS の設定 | 触らない |

## スマホメニューについて

- 900px以下ではハンバーガーメニュー（右上の ☰）方式です。タップすると全7ページが縦リストで出ます。
  （旧版にあった「メニュー横スクロール」の上書きCSSは 2026-11-03 に廃止済み）
- PCでは従来どおり上部の横並びメニューです。

## 文章はフォームで編集できます（コード不要）

- 文章は `content/*.json` に分離し、Pages CMS では日本語ラベルの入力フォームとして表示されます
- ページ側はそのデータを自動で読み込んで表示します。読み込めない場合はHTML内の予備文章が表示されます
- Muse にチャットで頼む編集も、同じ `content/*.json` を書き換えるので、どちらの方法でも大丈夫です
- 詳しくは `EDITING.md` を見てください

## なぜスマホで編集しやすくなったか

- 元の版：1ファイル 約129KB（ロゴ画像のデータが2回埋め込まれていた）
- この版：1ページ 約3〜4KB ＋ 共通ファイル（デザインとロゴは1回だけ置く）
- 直したいページのファイルだけ開けばいいので、スマホでも迷子になりにくい
- 各ファイルの中に `<!-- ここから編集OK -->` 〜 `<!-- ここまで -->` の目印つき。
  その内側の日本語の文章だけ直せばOK。外側（ヘッダー・フッター）は全ページ共通部品です。

## スマホでの編集の流れ（公開後）

### 方法A：Pages CMS（おすすめ）
1. iPhoneのブラウザで Pages CMS（app.pagescms.org）を開く
2. GitHubアカウントでログインし、このサイトのリポジトリを選ぶ
3. 一覧から直したいページ（例：お知らせ）を選んで文章を直す
4. 保存すると GitHub に反映され、Cloudflare Pages が自動で公開を更新する（目安1分ほど）

### 方法B：GitHubの画面で直接
1. iPhoneのブラウザで GitHub のリポジトリを開く
2. 直したいファイル（例：`news.html`）→ 鉛筆マーク → 文章を直す
3. 「Commit changes」を押すと、同じく自動で公開が更新される

## 公開の流れ（まだ未実施）

1. GitHubアカウントを作り、このフォルダ一式をリポジトリに上げる
2. Cloudflare Pages でそのリポジトリを接続し、無料アドレス `○○.pages.dev` で公開
3. 本公開のタイミングで、各HTMLの `<meta name="robots" content="noindex,follow">` の行を削除する
   （今は「公開準備中」として検索に出ない設定のままにしてあります）

※アカウント作成・公開は、Yfutの確認を取ってから行います。この一式だけではまだネットに出ていません。
